# Заправки Тюмени

Учебный проект по дисциплине «Базы данных»: база PostgreSQL с перечнем АЗС Тюмени и отметками о наличии топлива и веб-приложение на Python (Flask). По каждой из 8 таблиц в нём есть просмотр, добавление, изменение и удаление записей.

Автор: Игорь Куваев.

## Как подключиться к базе

PostgreSQL 14 или новее. База `azs`, кодировка UTF-8.

| Параметр | Значение |
| --- | --- |
| Хост | `localhost` |
| Порт | `5432` |
| Имя базы | `azs` |
| Пользователь | `postgres` |
| Пароль | тот, что задан при установке PostgreSQL |

Строка подключения записана в файле `config.py`. Вместо слова `ПАРОЛЬ` впиши свой пароль:

```
DATABASE_URL = "postgresql://postgres:ПАРОЛЬ@localhost:5432/azs"
```

## Как создать таблицы

Файл `schema.sql` создаёт базу `azs`: домены, 8 таблиц, триггеры, представление `fuel_status` и учебные данные. Его выполняют, подключившись к базе `postgres`.

Windows (PowerShell, из папки проекта; `18` — номер установленной версии PostgreSQL):

```
& "C:\Program Files\PostgreSQL\18\bin\psql.exe" -h localhost -U postgres -d postgres -f schema.sql
```

macOS и Linux:

```
psql -h localhost -U postgres -d postgres -f schema.sql
```

Несколько `ERROR` в конце вывода — это нормально: так файл проверяет, что база отказывается принимать неверные данные.
Повторный запуск стирает базу `azs` и собирает её заново. Перед этим останови приложение.

## Как запустить приложение

Нужен Python 3.10 или новее. Команды выполняются в папке проекта.

Первый раз:

```
py -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

Запуск:

```
.venv\Scripts\python -m flask --app app run
```

Приложение открывается по адресу http://127.0.0.1:5000. Остановить — Ctrl + C в терминале.

На macOS и Linux вместо `py` пиши `python3`, а вместо `.venv\Scripts\python` — `.venv/bin/python`.

| `config.py` | строка подключения к базе |
| `requirements.txt` | библиотеки Python: Flask и psycopg |
